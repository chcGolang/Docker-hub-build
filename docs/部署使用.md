# 部署使用文档

本仓库构建的多项目 Docker 镜像均发布到 Docker Hub。本文档说明通用约定，并按项目给出具体部署示例。

> **新增项目时**：在本文档末尾追加该项目的部署小节，并在 [README 项目列表](../README.md) 补一行。

## 通用约定

### 镜像命名与 tag

- 镜像：`chcgolang/<项目>`
- tag：`latest` 始终指向最新构建版本；同时存在 `:<版本号>` 的精确版本 tag，例如 `opencode:1.0.180`
- 多架构：镜像同时支持 `linux/amd64` 与 `linux/arm64`，Docker 会自动拉取匹配宿主架构的版本

### 拉取镜像

```bash
docker pull chcgolang/<项目>:latest
```

### 通用部署建议

- 项目工作目录一般挂载到容器内的 `/workspace`
- Web 服务如需对外访问，务必设置鉴权密码（各项目用各自的环境变量，见对应小节）
- 建议将配置与状态目录挂载为数据卷，避免容器重建后数据丢失
- 容器内二进制支持自更新（默认开启）；镜像重建是持久更新路径，见各小节"更新机制"

## opencode

OpenCode AI 编程代理的 Web 界面镜像，基于 Debian (trixie)。启动后默认监听 `0.0.0.0:4096`，可通过浏览器访问。

- 镜像：`chcgolang/opencode`
- 端口：`4096`
- 版本：自动取 opencode 官方最新 release

### 快速部署（docker run）

```bash
docker run -d --name opencode \
  -p 4096:4096 \
  -v "$PWD/workspace:/workspace" \
  -v opencode-config:/root/.config/opencode \
  -v opencode-share:/root/.local/share/opencode \
  -v opencode-state:/root/.local/state/opencode \
  -v opencode-cache:/root/.cache/opencode \
  -e OPENCODE_SERVER_PASSWORD='你的密码' \
  chcgolang/opencode:latest
```

### 参数说明

| 参数 | 说明 |
|------|------|
| `-p 4096:4096` | 将容器 4096 端口映射到宿主机 |
| `-v "$PWD/workspace:/workspace"` | 挂载宿主机项目目录作为容器工作目录（容器内默认 `/workspace`） |
| `-v opencode-config:/root/.config/opencode` | 持久化 opencode 配置（模型配置、插件等） |
| `-v opencode-share:/root/.local/share/opencode` | 持久化认证凭据 |
| `-v opencode-state:/root/.local/state/opencode` | 持久化会话与项目数据（**重建容器前必须保留**，否则会话丢失） |
| `-v opencode-cache:/root/.cache/opencode` | 持久化缓存 |
| `-e OPENCODE_SERVER_PASSWORD='你的密码'` | 设置 Web 访问鉴权密码（强烈建议启用） |
| `-e OPENCODE_SERVER_USERNAME='用户名'` | 可选，鉴权用户名，默认 `opencode` |

### 看门狗参数（自更新自动重启）

镜像内 `watchdog.sh` 负责在 opencode 自更新后，于**空闲时自动重启** web 进程使新版生效。以下环境变量均可选：

| 环境变量 | 默认 | 说明 |
|---------|------|------|
| `OPENCODE_WATCH_POLL_SECONDS` | `30` | 版本与空闲检测间隔（秒） |
| `OPENCODE_WATCH_IDLE_MINUTES` | `30` | 状态目录无写入超过该分钟数才算空闲 |
| `OPENCODE_WATCH_MAX_WAIT_MINUTES` | `480` | 待重启最长等待时间（分钟），超时后进入兜底 |
| `OPENCODE_WATCH_MAINTENANCE_START` | `03:00` | 兜底强制重启窗口开始（按容器本地时间，默认 UTC） |
| `OPENCODE_WATCH_MAINTENANCE_END` | `04:00` | 兜底强制重启窗口结束 |
| `OPENCODE_WATCH_FORCE_FALLBACK` | `0` | 兜底开关，设 `1` 才允许维护窗口强制重启；默认无限期等待空闲 |
| `OPENCODE_PORT` | `4096` | opencode web 监听端口（与 `-p` 映射一致） |

### 数据目录

opencode 数据分散在 4 个目录（XDG 规范）：

| 类型 | 容器内路径 |
|------|-----------|
| 配置 | `/root/.config/opencode` |
| 认证 | `/root/.local/share/opencode` |
| 状态（会话/项目 DB） | `/root/.local/state/opencode` |
| 缓存 | `/root/.cache/opencode` |

> **注意**：会话与项目数据存放在 state 目录。更新镜像执行 `docker rm -f opencode` 前，确认 state 卷已挂载且保留，否则所有会话记录会被清空。

### 访问

浏览器打开 `http://<主机IP>:4096`，使用设置的用户名/密码登录。

### docker compose 示例

```yaml
services:
  opencode:
    image: chcgolang/opencode:latest
    container_name: opencode
    ports:
      - "4096:4096"
    environment:
      OPENCODE_SERVER_PASSWORD: "你的密码"
      # 可选：看门狗参数（自更新后空闲自动重启，见"看门狗参数"小节）
      # OPENCODE_WATCH_IDLE_MINUTES: 30
      # OPENCODE_WATCH_FORCE_FALLBACK: 0
    volumes:
      - ./workspace:/workspace
      - opencode-config:/root/.config/opencode
      - opencode-share:/root/.local/share/opencode
      - opencode-state:/root/.local/state/opencode
      - opencode-cache:/root/.cache/opencode
    restart: unless-stopped

volumes:
  opencode-config:
  opencode-share:
  opencode-state:
  opencode-cache:
```

### 更新机制

- **容器内自更新 + 自动重启**：opencode 默认开启自更新，具体检查时机由 OpenCode 自身决定。镜像内的看门狗检测到版本变化后，会在**判断为空闲时自动重启** web 进程使新版生效，无需手动 `docker restart`。
  - **空闲定义**：4096 端口无活跃连接，且状态目录近 `OPENCODE_WATCH_IDLE_MINUTES` 分钟无写入，两者同时满足才算空闲。
  - **默认不强制中断**：只要未判定为空闲就一直等待；由于空闲是基于连接和文件写入的启发式判断，不能对后台任务提供绝对保证。
  - **可选超时兜底**：只有设置 `OPENCODE_WATCH_FORCE_FALLBACK=1` 时，若持续使用超过 `OPENCODE_WATCH_MAX_WAIT_MINUTES`（默认 480），才会在维护窗口（`OPENCODE_WATCH_MAINTENANCE_START` ~ `_END`）内强制重启一次。
  - 容器被删除重建后会回到镜像内烧入的版本。
- **镜像重建（持久更新路径）**：CI 每天 UTC 02:00 检测 opencode 官方新版本，版本变化时重新构建并推送 `latest` + `:<版本号>`。更新步骤：
  ```bash
  docker pull chcgolang/opencode:latest
  docker rm -f opencode
  # 重新执行上方的 docker run 或 docker compose up -d
  ```

### 常见操作

```bash
docker logs opencode          # 查看日志
docker restart opencode       # 重启
docker rm -f opencode         # 删除容器
```
